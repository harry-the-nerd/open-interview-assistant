04 — Flow

One shortcut. Full interview script.

Open the question in Chrome, press the hotkey, speak from the panel while you type.

STEP 01

Open the question

LeetCode, a doc, a take-home brief — anything in Chrome. The extension only reads when you ask.

STEP 02

Press ⌘⇧U

Page text hits the local overlay over loopback. Pairing is automatic after first setup.

STEP 03

Speak the answer

Scroll with keyboard shortcuts. Dock left or right. Hide instantly if you need a clean screen.

06 — Trust model

Local-first. Least privilege. No suspicious indicators.

The extension only talks to your machine. The model only sees page text you explicitly send.

DOES

What this project does

  • Invisible on share/capture — content protection hides the panel
  • Page text only — no screenshots, no continuous capture, no system audio
  • activeTab + scripting — reads the current tab when you press the shortcut
  • Loopback-only server — 127.0.0.1 with token auth, origin checks, body caps, rate limits
  • No broad host access — no “read all websites” permission
AVOIDS

What it deliberately avoids

  • No microphone access — never listens, no mic privacy light
  • No screen/system recording permission — nothing that triggers the capture indicator
  • No mouse-stealing UI — overlays that grab clicks look unnatural on camera
  • No cloud account required — bring your own Anthropic API key
  • No silent re-pairing forever — recovery is a deliberate keystroke

08 — Get started

Clone, key, run, load unpacked.

Local Electron app + a plain Chrome extension. No build step for the extension.

terminalsetup
# clone
git clone https://github.com/harry-the-nerd/open-interview-assistant.git
cd open-interview-assistant

# install + configure
npm install
echo 'ANTHROPIC_API_KEY=sk-ant-...' > .env

# run the overlay
npm run dev

Load the extension once

  1. Open chrome://extensions and enable Developer mode.
  2. Click Load unpacked and select the repo’s extension/ folder.
  3. With the app running, pairing happens automatically on install, browser startup, or the first ⌘⇧U.
  4. If the shortcut collides, rebind it at chrome://extensions/shortcuts — or change the app bindings and make them yours.
